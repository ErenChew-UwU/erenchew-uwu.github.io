# Tool Design Reference

This tool intentionally uses a different visual direction from the main portfolio shell.

- Centered layout with empty left and right desktop margins.
- Warm paper background, teal/coral/gold accents, and compact calculator panels.
- No main portfolio header; the tool has a smaller purpose-built header.
- Every condition is vertically stacked and follows the required format: name, slider/control, current value, coefficient, and live interpretation.
- Sliders show node/tick labels so each step has visible context.
- Illustration base pricing uses two select boxes: main category first, then style/service level.
- Presets are loaded from sequential JSON files and exposed through the header selector.
- Tool files are self-contained in this directory.
